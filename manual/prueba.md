

### --track オプション

　実行時点のタイムスタンプで、指定されたファイルにステータスを記録します。

```
 prueba.sh --track [-d DESCRIPTION] STATUS RUNFILE...
 STATUS := READY|BLOCK|PASS|FAIL|RUN
```

### --log オプション

　指定された run file のログを出力します。

```
 prueba.sh --log RUNFILE...
```

### --report オプション

　指定された run file のログを出力します。

```
 prueba.sh --report [-c CONF_FILE]
```
